# Reference Paper 说明

本目录存放本项目可直接参考的论文资料，按用途分为两类：

- `topic_paper/`
  与本项目研究对象、研究主题直接相关的论文，重点覆盖新质生产力、粤港澳大湾区协同发展、耦合协调、障碍诊断、空间演化等内容。
- `model_paper/`
  与本项目方法路线高度相关的论文，重点覆盖熵权法、耦合协调度模型、空间杜宾模型、空间溢出、收敛分析、障碍因子和时空演化等内容。

## 命名规则

为避免原始数字文件名不可读，本目录已统一改为“保留原编号 + 内容型文件名”的命名方式。

- 编号 `01-09` 对应 `topic_paper/`
- 编号 `10-15` 对应 `model_paper/`

保留编号的目的是方便和你原先整理顺序、模型设计文档中的文献引用顺序一一对应。

## 建议优先阅读顺序

如果你是为了当前项目直接服务，建议按下面顺序读：

1. `05`、`06`、`09`
   先抓住与你的研究区域和方法最接近的三篇，大湾区协同发展、耦合协调和障碍诊断的骨架都在这里。
2. `01`、`03`、`04`
   再补新质生产力测度和区域差异的指标与理论支撑，用来稳住 U1 系统设计。
3. `10`、`12`
   接着看空间杜宾模型和“辐射/虹吸”机制的写法，服务第六步。
4. `07`、`08`
   再补大湾区时空演化和网络结构解释，服务第四步和结论讨论。
5. `11`、`13`、`14`、`15`
   作为方法扩展、稳健性比较和论文写作时的辅助参考。
