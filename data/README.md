- 可直接用于建模或预处理的年度面板数据

## 面板数据说明

### 1. `population_2015_2024_11cities.csv`

- 内容：2015-2024 年粤港澳大湾区 11 城人口数据
- 字段：
  `Year`、11 个城市字段、`Source_URL`
- 单位：千人
- 口径：
  内地城市为年末常住人口；香港为年底居住人口；澳门为年终人口
- 官方来源：
  澳门统计暨普查局“粤港澳大湾区统计专页”11 城统一表
- 使用建议：
  可直接用于构造人口规模、人均指标分母、人口密度等变量

### 2. `gdp_2015_2024_11cities.csv`

- 内容：2015-2024 年粤港澳大湾区 11 城 GDP 数据
- 字段：
  `Year`、11 个城市字段、`Source_URL`
- 单位：
  内地城市为亿元人民币；香港为亿港元；澳门为亿澳门元
- 口径说明：
  香港为本地生产总值，澳门为本地生产总值，内地城市为地区生产总值
- 官方来源：
  澳门统计暨普查局“粤港澳大湾区统计专页”11 城统一表
- 使用建议：
  若用于跨城比较、标准化或耦合协调建模，建议先按年度平均汇率将香港和澳门折算为人民币

### 3. `employment_2015_2024_11cities.csv`

- 内容：2015-2024 年粤港澳大湾区 11 城就业数据
- 字段：
  `Year`、11 个城市字段、`Source_URL`
- 单位：万人
- 口径：
  内地城市为年末数字；港澳为年度数字
- 官方来源：
  澳门统计暨普查局“粤港澳大湾区统计专页”11 城统一表
- 特别说明：
  2015-2023 年为表中精确值，2024 年就业值来自大湾区统计专页网页显示值
- 使用建议：
  可直接用于构造就业规模、就业率相关替代变量，或与 GDP、人口结合构造劳动生产率类指标

## 资料型文件说明

### 4. `city_official_links.csv`

- 内容：11 城及港澳官方统计入口、年鉴入口、时间序列入口
- 用途：
  后续补采科技、专利、教育、贸易、产业升级、ICT 等指标时的官方导航表
- 适合场景：
  指标扩展、缺失值回查、原始数据核验

### 5. `indicator_source_map.csv`

- 内容：按系统维度整理的指标建议及官方来源映射
- 覆盖方向：
  新质生产力、区域协调
- 主要用途：
  后续构建双系统指标体系时，快速定位每个指标应该去哪个官方来源补采
- 使用建议：
  先从 11 城统一可比指标入手，再逐步扩展到研发、专利、教育、开放联通、公共服务等指标

### 6. `literature_2023_2025.csv`

- 内容：2023-2025 年与新质生产力、耦合协调、空间效应、大湾区协同发展相关的文献清单
- 主要用途：
  文献综述、理论机制梳理、方法路线对照
- 使用建议：
  可优先筛选与“新质生产力测度”“耦合协调+障碍因子”“大湾区空间协同”最接近的文献

### 7. `official_background.csv`

- 内容：国家战略文件、11 城范围定义、港澳官方统计年刊、11 城统一统计平台等背景链接
- 主要用途：
  论文引言、政策背景、研究范围界定、数据来源说明

## 拆分规则说明

本次拆分采用以下规则：

1. `README` sheet 不再保留为表格文件，而是转换为当前这份 `README.md`。
2. `Population_2015_2024`、`GDP_2015_2024`、`Employment_2015_2024` 三张 sheet 拆分为独立 CSV。
   为方便后续代码读取，CSV 仅保留表头和年度数据行，工作表末尾的单位/补充说明已移入本说明文档。
3. `City_Official_Links`、`Indicator_Source_Map`、`Literature_2023_2025`、`Official_Background` 四张资料型 sheet 全量导出为 CSV。
4. 所有新导出的 CSV 统一保存为 `UTF-8 with BOM` 编码，便于 Windows 下用 Excel 直接打开。

## 建模与使用注意

1. 货币口径不统一。
   `gdp_2015_2024_11cities.csv` 中，香港和澳门不是人民币口径，正式建模前必须折算。
2. 人口与就业定义存在跨地区差异。
   内地、香港、澳门的人口和就业统计口径不完全一致，论文中应主动说明。
3. 当前可直接比较的完整 11 城面板数据只有人口、GDP、就业三类。
   新质生产力核心指标仍需依据 `indicator_source_map.csv` 和 `city_official_links.csv` 继续补采。
4. `Source_URL` 字段是重要元数据。
   处理脚本如不需要该字段，可在读取后分离；但建议保留用于回溯核验。
5. 原始总表已经删除。
   当前以拆分后的 CSV 和本说明文档为准；若后续还要继续人工维护，建议新建结构化工作簿，而不是再回到汇总大表。

## 推荐使用顺序

1. 先阅读本文件，明确哪些数据已经可直接使用。
2. 用三张面板 CSV 进行基础描述、标准化和耦合协调测度。
3. 用 `indicator_source_map.csv` 补齐双系统指标体系。
4. 用 `city_official_links.csv` 回到各城市官方来源下载或核验数据。
5. 用 `literature_2023_2025.csv` 和 `official_background.csv` 支撑论文写作与方法说明。
